# Сафонов Артём Витальевич 2013 курсовая работа по предмету ТПР
## Тема
Принятие решений в задаче распознавания образов с использованием нейронной сети

## Описание
Проект реализует классификацию изображений:

мусорные мешки
пластиковые пакеты
бумажные пакеты

## Используемые технологии
1. Python
2. TensorFlow
3. Keras
4. NumPy

## Структура проекта
1. main.py — обучение модели
2. predict.py — предсказание
3. dataset/ — датасет
4. bag_classifier.keras — обученная модель

## Важно!
Датасет не включён в репозиторий из-за большого объёма данных.
